1. Скопируйте ribbon-constructor.css и ribbon-constructor.js в корень репозитория dashusav-lab/fonts, рядом с файлами шрифтов. Не в подпапку fonts.
2. Сделайте Commit и Push origin через GitHub Desktop.
3. После публикации файлов скопируйте весь текст из tilda-short-code.txt в HTML-блок T123 вместо прежнего длинного кода.
4. Сохраните и опубликуйте страницу Tilda. Проверяйте на опубликованной странице.

Список шрифтов и фильтры сохранены. Результаты текущей проверки вынесены вместе с кодом в ribbon-constructor.js. Будущие изменения каталога по-прежнему обслуживает ранее подготовленная автоматизация font-catalog.json.

В редактор вставляется только содержимое tilda-short-code.txt. Файлы CSS и JS в HTML-блок не копируйте.

Файлы ещё не опубликованы в GitHub автоматически. Короткий код заработает после шага 2 и появления файлов в CDN. При дальнейшей замене CSS/JS обновление CDN может занять время.
